# KISSViewer

KiSS（着せ替え）データを見て、動かして遊ぶための Windows 用ビューアです。PC-98 版 KISS.EXE（v2.50d）の見た目と動きに合わせています。表示専用で、データは書き換えません。

> このリポジトリは、配布と不具合報告のためのものです。ソースコードは公開していません。

## 主な特長

- **KiSS / FKiSS**：CNF・CEL・KCF（12/24ビット、複数パレット）を表示し、左ドラッグで動かせます。FKiSS（拡張命令）と FKiSS2 系の命令、イベント、半透明（Cherry KiSS）に対応しています。
- **2つの見せ方**：PC-98 版と同じ画面（ファンクションエリア付き）と、全体を窓に入れるモダン表示を切り替えられます。倍率は 100%〜400%。
- **書庫のまま読める**：フォルダ・LZH・ZIP・RAR（7-Zip か WinRAR が必要）をドロップするだけです。CNF が複数あるときは選べます。
- **音**：効果音（WAV・AU）と MIDI を鳴らします。
- **PC-98 のフォント**：お持ちの FONT.ROM から文字のフォントを作れます（ROM は同梱していません）。

使い方は、アプリの［ヘルプ］をご覧ください。

## 動作環境

- Windows 10 以降の 64 ビット版（動作確認は Windows 11）

## インストール

1. [Releases](https://github.com/agustaf4s/KISSViewer/releases) から、最新の版をダウンロードします。
2. 実行して、画面の案内に従います（または、展開して `KISSViewer.exe` を起動します）。
3. データ（フォルダ・書庫・CNF）を、窓へドラッグ＆ドロップします。

設定は `%LOCALAPPDATA%\KISSViewer` に保存されます。アンインストールしても残るので、不要なら手で削除してください。
